# 桌面签 DeskTodo

一个类似“敬业签”的 Windows 桌面便签式待办软件。常驻桌面角落，随手记录待办，到点弹窗提醒。

## 功能

- **桌面便签窗口**：无边框、半透明、可置顶，可拖动和调整大小，位置自动记忆。
- **贴边自动隐藏**：把窗口拖到屏幕上、左、右边缘，鼠标离开后缩成一条细边，鼠标移过去自动展开。
- **自然语言添加提醒**：直接输入“明天下午3点开会”“10分钟后喝水”“周五 9:30 交周报”“下周一上午十点例会”，自动识别时间。
- **定时提醒**：到点弹出系统通知和置顶提醒小窗，可“完成”“稍后提醒（5 分钟到 3 小时）”“查看”，并有提示音。
- **重复提醒**：每天、工作日、每周、每月、每年。完成后自动生成下一次。
- **分类**：默认“待办 / 工作 / 生活”，可增删改名和改颜色；把待办拖到分类标签上即可移动分类。
- **整理**：拖动排序、标记重要（置顶显示）、标记颜色、备注、双击行内编辑、搜索（Ctrl+F）、删除可撤销。
- **已完成**：按日期分组查看，可恢复或一键清空。
- **外观**：6 种主题（蓝、绿、粉、便签黄、紫、深色），可调不透明度和字体大小。
- **托盘常驻**：关闭窗口不退出；托盘菜单可切换置顶、贴边隐藏、锁定位置、开机自启。
- **全局快捷键**：默认 `Ctrl+Alt+D` 显示或隐藏，可在设置里重新录制。
- **数据安全**：数据存在本机 `%APPDATA%\桌面签\data.json`，原子写入防断电损坏；支持导出和导入 JSON 备份。

## 下载安装

推送代码后，GitHub Actions 会在 Windows 环境自动打包。在仓库的 **Actions → Build Windows** 中打开最新一次运行，下载 `DeskTodo-windows` 产物，里面有两个文件：

- `DeskTodo-Setup-1.0.0.exe`：安装版，可选安装目录，创建桌面快捷方式。
- `DeskTodo-Portable-1.0.0.exe`：免安装版，双击即用。

推送 `v1.0.0` 这样的标签时，会自动发布到 Releases。

## 从源码运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm start          # 开发运行
npm test           # 单元测试
npm run dist       # 在 Windows 上打包安装版和免安装版，输出到 dist/
```

## 快捷操作

| 操作 | 方式 |
| --- | --- |
| 新建待办 | 输入框回车，或 `Ctrl+N` |
| 设置提醒时间 | 输入框右侧 ⏰，或悬停待办点 ✎ |
| 编辑内容 | 双击待办文字 |
| 完成 | 点左侧圆圈 |
| 标为重要 | 悬停点 ☆ |
| 搜索 | `Ctrl+F` |
| 关闭弹出面板 | `Esc` |
| 显示/隐藏窗口 | `Ctrl+Alt+D` 或单击托盘图标 |

## 代码结构

```
src/main.js                 主进程：窗口、托盘、提醒调度、贴边隐藏、快捷键、数据读写
src/core.js                 纯逻辑：数据结构、重复规则、提醒判定（有单元测试）
src/preload.js              安全桥接，渲染进程只能调用白名单接口
src/renderer/index.html     主界面
src/renderer/app.js         主界面逻辑
src/renderer/parse-time.js  中文时间识别（有单元测试）
src/renderer/reminder.*     提醒弹窗
scripts/gen-icon.js         生成应用图标 build/icon.png
```
