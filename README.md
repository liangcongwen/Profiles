# 警情案件线索跟进系统

一个在 Windows 上运行的单机桌面软件，用来登记和跟进警情、案件、线索。数据保存在本机的 SQLite 数据库里，不联网，不需要安装数据库。

## 功能

- **工作台**：显示三类事项的未办结数量和各状态分布，列出已逾期和 3 天内到期的待办提醒。
- **警情**：登记报警时间、类别、报警人、地点、处置民警和处置结果。可一键“转为案件”，自动带入信息并互相关联。
- **案件**：登记案件名称、类别、主办和协办民警、当事人、嫌疑人和涉案金额。打开案件可看到所有关联的警情和线索。
- **线索**：登记来源、优先级、核查期限和负责人，可关联到案件。超过核查期限的线索在列表里标红。
- **跟进记录**：每条警情、案件、线索都可以添加多条跟进，记录跟进人、内容、下一步工作和下次跟进日期。到期的下次跟进会出现在工作台提醒里。
- **查询筛选**：按关键字、状态（含“未办结”）和日期范围筛选，点表头排序。
- **导出**：当前列表导出为 CSV，可直接用 Excel 打开，中文不乱码。
- **备份**：菜单“文件 → 备份数据库”可随时把数据另存一份。

编号自动生成，格式为前缀加日期加序号，例如 `JQ20261001-001`（警情）、`AJ…`（案件）、`XS…`（线索），也可以手工修改。

## 在 Windows 上使用

### 方式一：下载打包好的 exe（推荐，不需要装 Python）

每次推送代码，GitHub Actions 都会在 Windows 上自动打包。

1. 打开仓库的 **Actions** 页面，点进最新一次“打包 Windows 程序”运行记录。
2. 在页面底部 **Artifacts** 里下载 `CaseTracker-windows`，解压得到 `CaseTracker.exe`。
3. 把 `CaseTracker.exe` 放到一个固定文件夹，例如 `D:\警情系统\`，双击运行。

首次运行会在 exe 旁边自动创建 `data` 文件夹，数据库文件是 `data\case_tracker.db`。拷贝整个文件夹即可迁移到其他电脑。

### 方式二：用本机 Python 运行

1. 安装 [Python 3.8 或以上版本](https://www.python.org/downloads/windows/)，安装时勾选 “Add Python to PATH”。
2. 下载本仓库代码，双击 `start.bat` 启动。

### 自己打包 exe

在装好 Python 的 Windows 电脑上双击 `build_exe.bat`，完成后得到 `dist\CaseTracker.exe`。

## 数据与安全提示

- 数据只存在本机。请定期用“备份数据库”功能备份，并把备份放在安全的位置。
- 本软件没有登录和权限控制，适合个人或单机使用。涉及敏感信息时，请按单位的保密规定使用，例如放在加密磁盘或内网专用电脑上。
- 可以用环境变量 `CASE_TRACKER_DATA` 指定其他数据目录。

## 开发

```
python -m case_tracker                 # 启动程序
python -m unittest discover -s tests   # 运行测试
```

代码结构：

- `case_tracker/schema.py`：三类记录的字段、状态和下拉选项。想增删字段或修改选项，改这里即可，界面和数据库会自动跟随，老数据库会自动补新增的列。
- `case_tracker/db.py`：数据库读写、提醒计算、导出和备份。
- `case_tracker/gui.py`：Tkinter 界面。
